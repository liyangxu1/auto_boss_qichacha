# 本地工作台设计

工作台设计参考在本地保留，公开分支仅包含设计说明。

界面采用白底、深色中文无衬线字体、翠绿主色 #128269、浅薄荷选中态。顶栏 64px，桌面主区域为简历搜索 / 岗位列表 / 详情三栏；左栏 280px，中栏自适应，右栏 340px。圆角 8px，细灰分隔线，正文 14px，区域标题 18px，页面标题 34px。图标统一使用 24x24、1.7px 线宽的 SVG。

允许文案：AutoBOSS、求职工作台、评分规则、本地工作台、让下一份工作，更适合你。、从一份简历开始，把搜索、筛选与匹配连在一起。、上传简历、调整搜索、采集岗位、匹配排序、准备就绪、暂停采集、简历与搜索、上传 PDF 简历、求职方向、城市、工作经验、搜索关键词、添加关键词、AI 重新生成建议、开始搜索岗位、岗位列表、全部岗位、已匹配、待匹配、开始 AI 匹配、岗位详情、职位信息、匹配分析、公司信息、公司概况、在 BOSS 查看。任务状态、文件名、岗位内容、数量和评分由真实数据决定。

组件：应用壳、任务进度、简历和搜索编辑器、岗位列表、详情检查器、评分规则弹窗、简历编辑弹窗。960px 以下详情转为下方区域，640px 以下顺序显示，不产生横向滚动。

必要交互：上传解析、编辑简历、AI 生成关键词、保存搜索条件、连接独立 BOSS 窗口、扫码后采集、暂停和继续、列表筛选排序、评分维度/权重/提示词编辑、匹配结果证据展示、JSON 导出。真实模型调用和采集不伪装为示例数据。

图像提示词：完整中文求职工作台，白底与翠绿三栏布局，简历上传和搜索条件、真实历史岗位列表、岗位详情及公司资料；评分弹窗包含七个可编辑维度、权重、评分要点、提示词和最低完整度。生成图仅作设计参考，应用全部以代码控件实现。
